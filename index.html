Persiapan

Mulai dari web kantin sederhana

Dalam praktikum ini kamu membangun PWA secara bertahap. Setelah tiap langkah, simpan perubahan dan periksa hasilnya sebelum lanjut.

  1. Buka web awalMenu dan subtotal sudah berfungsi.
  2. Ubah tampilanKartu mengikuti lebar layar.
  3. Tambahkan PWAAplikasi memiliki ikon dan cache.
  4. Uji hasilBuka ulang saat server mati.

Sudah disediakan

index.html untuk struktur, style.css untuk gaya awal, app.js untuk menu dan subtotal, serta dua gambar ikon PNG.

Akan kamu tambahkan

Aturan CSS responsif, manifest.webmanifest, dan sw.js. Setiap potongan kode punya petunjuk nama file dan lokasi penempelan.

Peralatan: laptop, VS Code, Chrome atau Edge, serta ekstensi Live Server oleh Ritwick Dey. Untuk uji ponsel, gunakan tautan HTTPS yang disiapkan dosen.

Buka panduan HTML langsung di browser jika tombol pada pratinjau LMS tidak berfungsi.

Istilah yang dipakai

Kenali cara kerja PWA lewat Kantin Kampus

PWA

Aplikasi web yang bisa dipasang dari browser. Kantin Kampus juga disiapkan agar daftar menu bisa dibuka saat offline.

Viewport

Ibarat bingkai tempat halaman terlihat. Saat bingkai menyempit, dua kolom kartu menu berubah menjadi satu.

Manifest

Seperti kartu identitas aplikasi. Isinya menentukan nama, ikon, dan halaman awal saat ikon Kantin Kampus ditekan.

Service worker

Seperti petugas di belakang layar. Saat browser meminta berkas, skrip ini bisa mengambil salinan di perangkat atau meminta berkas ke server.

Cache Storage

Seperti rak penyimpanan di browser. Demo menaruh salinan halaman, CSS, dan JavaScript di sini agar bisa dipakai lagi saat server mati.

Localhost

Alamat yang menunjuk ke perangkat sendiri. Di laptop, Live Server menyajikan Kantin Kampus lewat alamat seperti 127.0.0.1:5513.

Cache menyimpan berkas aplikasi. Jumlah porsi yang kamu pilih hanya berada di memori halaman, sehingga kembali ke nol setelah halaman dimuat ulang.

Langkah 1

Jalankan proyek awal

  1. Ekstrak ZIP.

    Di VS Code, pilih File → Open Folder. Buka folder kantin-pwa-latihan hasil ekstraksi.

  2. Pasang Live Server.

    Tekan Ctrl+Shift+X, cari Live Server oleh Ritwick Dey, lalu pilih Install. ID ekstensi ritwickdey.LiveServer.

  3. Buka aplikasi.

    Di Explorer VS Code, klik kanan index.html, pilih Open with Live Server, lalu buka hasilnya di Chrome atau Edge. Paket awal memakai port 5513. Catat URL persis dari bilah alamat karena port dapat berbeda.

Cek hasil: menu terlihat, subtotal bisa dihitung, dan label Offline belum disiapkan masih tampil. Jika kamu pernah memakai demo pada URL dan port yang sama, pakai port baru atau bersihkan data demo seperti pada bagian pengujian.

Langkah 2

Ubah kartu menu agar responsif

Proyek awal memakai dua kolom di semua lebar. Kita ingin ponsel memakai satu kolom agar kartu mudah dibaca.

Tempat menempel: buka style.css, lalu tambahkan potongan ini di akhir file.

style.css · Tambahkan di akhir file
@media (max-width: 560px) {
  .menu-grid {
    grid-template-columns: 1fr;
  }
}

max-width: 560px berarti aturan aktif pada lebar 560 piksel CSS atau kurang. 1fr membuat satu kolom mengisi ruang grid yang tersedia. Pada layar lebih lebar, aturan dua kolom dari file awal tetap berlaku.

Pratinjau interaktif

Ubah 0 menjadi 560, klik Terapkan CSS, lalu bandingkan dua lebar layar.

.menu-grid { display: grid; grid-template-columns: 1fr 1fr; }
@media (max-width: px) {
  .menu-grid { grid-template-columns: 1fr; }
}
Pratinjau 390 px · batas 0 px

Gunakan kontrol di atas untuk melihat efeknya. Simpan style.css di VS Code untuk mengubah aplikasi yang sebenarnya.

Cek hasil di demo: pada lebar 390 px kartu tersusun ke bawah. Pada lebar 720 px kartu berjajar dua kolom. Di Chrome DevTools, Ctrl+Shift+M membuka atau menutup tampilan perangkat setelah DevTools dibuka.

Langkah 3

Beri aplikasi nama dan ikon

Manifest adalah berkas konfigurasi yang memberi tahu browser cara menampilkan aplikasi saat dipasang.

  1. Buat file manifest.webmanifest.

    Buat di folder yang sama dengan index.html. Tempel JSON berikut, lalu simpan. Periksa nama file agar tidak berakhiran .txt.

manifest.webmanifest · Isi file baru
{
  "id": "./",
  "name": "Kantin Kampus",
  "short_name": "Kantin",
  "description": "Latihan katalog kantin yang dapat dibuka saat offline.",
  "lang": "id",
  "start_url": "./",
  "scope": "./",
  "display": "standalone",
  "background_color": "#f3f8fa",
  "theme_color": "#0b2740",
  "icons": [
    { "src": "./icon-192.png", "sizes": "192x192", "type": "image/png" },
    { "src": "./icon-512.png", "sizes": "512x512", "type": "image/png" }
  ]
}
  1. Tautkan manifest dari HTML.

    Di index.html, cari komentar <!-- Tambahkan tautan manifest di sini --> dalam bagian <head>. Ganti komentar itu dengan baris di bawah.

index.html · Ganti komentar pada head
<link rel="manifest" href="./manifest.webmanifest">

start_url menentukan halaman pertama saat ikon ditekan. scope menentukan area URL yang dianggap bagian aplikasi. Pada demo, ./ mengarah ke folder tempat manifest berada. theme_color menyarankan warna bilah antarmuka. background_color memberi warna latar saat aplikasi mulai dibuka. display: "standalone" meminta jendela aplikasi dengan antarmuka browser yang lebih minimal.

Cek hasil: muat ulang halaman. Buka F12 → Application → Manifest. Periksa nama Kantin Kampus dan kedua ikon. Kamu masih perlu menyiapkan cache untuk uji offline.

Langkah 4

Bangun service worker dalam tiga bagian

Service worker adalah skrip yang dijalankan browser untuk menangani permintaan dari halaman yang dikontrolnya. Cache Storage menyimpan salinan berkas yang dibutuhkan demo.

4A. Daftar berkas dan persiapan cache

Tempat menempel: buat sw.js di folder proyek, lalu tempel potongan berikut.

sw.js · Bagian 4A
const CACHE_PREFIX = "kantin-pwa-latihan:" + self.registration.scope + ":";
const CACHE_NAME = CACHE_PREFIX + "v1";

const FILES = [
  "./",
  "./index.html",
  "./style.css",
  "./app.js",
  "./manifest.webmanifest",
  "./icon-192.png",
  "./icon-512.png"
];

const FILE_URLS = FILES.map((file) => {
  return new URL(file, self.registration.scope).href;
});

self.addEventListener("install", (event) => {
  event.waitUntil((async () => {
    const cache = await caches.open(CACHE_NAME);
    const requests = FILE_URLS.map((url) => {
      return new Request(url, { cache: "reload" });
    });
    await cache.addAll(requests);
  })());
});

CACHE_NAME menamai salinan versi awal. FILES mencantumkan halaman, CSS, JavaScript, manifest, dan ikon. waitUntil(...) meminta browser menunggu sampai penyiapan selesai. Cache memuat alamat folder dan index.html agar kedua alamat bisa dibuka. Opsi cache: "reload" meminta berkas terbaru dari server saat mengisi Cache Storage. Jika satu file hilang, penyiapan bisa gagal.

4B. Pengaktifan dan pembersihan versi lama

Tempat menempel: tambahkan potongan berikut tepat di bawah bagian 4A dalam sw.js.

sw.js · Tambahkan bagian 4B
self.addEventListener("activate", (event) => {
  event.waitUntil((async () => {
    const names = await caches.keys();

    for (const name of names) {
      if (name.startsWith(CACHE_PREFIX) && name !== CACHE_NAME) {
        await caches.delete(name);
      }
    }

    await self.clients.claim();
  })());
});

Worker hanya menghapus cache lama milik latihan ini. clients.claim() membantu worker yang baru aktif mulai mengontrol halaman demo yang masih terbuka.

4C. Pengambilan halaman dari cache

Tempat menempel: tambahkan potongan berikut di bagian paling bawah sw.js, lalu simpan.

sw.js · Tambahkan bagian 4C
self.addEventListener("fetch", (event) => {
  const url = new URL(event.request.url);
  url.search = "";

  if (event.request.method !== "GET" || !FILE_URLS.includes(url.href)) {
    return;
  }

  event.respondWith((async () => {
    const cache = await caches.open(CACHE_NAME);
    const saved = await cache.match(url.href);

    return saved ?? fetch(event.request);
  })());
});

Untuk permintaan berkas yang ada dalam daftar, worker mencari salinan lebih dulu. Jika salinannya belum ada, worker mencoba server. Strategi ini disebut cache first.

Cek hasil: sw.js sekarang berisi bagian install, activate, dan fetch. Browser mulai menjalankannya pada langkah berikutnya.

Langkah 5

Daftarkan worker dari halaman

Tempat menempel: buka app.js. Tambahkan potongan ini di akhir file, setelah kode menu. Simpan, lalu muat ulang demo saat Live Server masih berjalan.

app.js · Tambahkan di akhir file
if (location.protocol !== "file:" && "serviceWorker" in navigator) {
  const status = document.querySelector("#cache-status");
  const worker = navigator.serviceWorker;
  status.textContent = "Menyiapkan cache…";

  function showReady() {
    if (worker.controller) {
      status.textContent = "Cache siap";
    }
  }

  worker.addEventListener("controllerchange", showReady);
  showReady();

  if (!worker.controller) {
    worker.register("./sw.js").then(showReady).catch((error) => {
      status.textContent = "Cache gagal disiapkan";
      console.error(error);
    });
  }
}

register("./sw.js") memberi tahu browser lokasi skrip. Setelah worker mengontrol halaman, controllerchange memicu pembaruan status. Tulisan Cache siap menjadi tanda untuk melanjutkan uji.

Cek hasil: status berubah menjadi Cache siap. Di Chrome DevTools, Application → Service Workers menampilkan sw.js. Application → Cache Storage menampilkan cache dengan akhiran v1.

Jika status belum berubah

Periksa nama file, termasuk kedua ikon. Pastikan URL dimulai dengan http://127.0.0.1, http://localhost, atau https://. Jika ada kesalahan, buka Console atau panel Service Workers sebelum mencoba lagi.

Langkah 6

Pasang aplikasi dan buka dari ikon

Biarkan demo tetap dapat diakses. Pilih satu perangkat untuk membuktikan instalasi.

Laptop · Chrome atau Edge

Klik ikon pasang di bilah alamat jika muncul. Bisa juga melalui menu browser, misalnya Instal halaman sebagai aplikasi.

Android · Chrome

Buka tautan HTTPS. Pilih ⋮ → Tambahkan ke layar utama, lalu pilih instal bila ditawarkan.

iPhone · Safari

Buka tautan HTTPS. Pilih Bagikan → Tambahkan ke Layar Utama. Aktifkan Buka sebagai App Web bila tampil.

  1. PasangGunakan opsi browser.
  2. Cari ikonCari Kantin Kampus pada peluncur aplikasi.
  3. Buka dari ikonPeriksa apakah daftar menu tampil.

Cek hasil: ikon membuka daftar menu. Pada mode standalone, bilah alamat lengkap biasanya tidak terlihat. Kemunculan opsi pemasangan dapat berbeda antarbrowser. Ponsel memakai tautan HTTPS, karena 127.0.0.1 di ponsel merujuk ke ponsel itu sendiri.

Pengujian akhir

Uji saat server mati, dengan dan tanpa cache

  1. Pastikan cache siap, lalu tutup aplikasi.

    Catat URL HTTP yang dipakai. Tutup tab dan jendela aplikasi Kantin Kampus.

  2. Hentikan akses ke server.

    Di VS Code, tekan Ctrl+Shift+P, pilih Live Server: Stop Live Server, lalu tekan Enter. Wi-Fi laptop boleh tetap menyala. Jika memakai ponsel, matikan Wi-Fi dan data seluler.

  3. Buka kembali dari ikon.

    Menu seharusnya tampil. Tekan Tambah dua kali pada Nasi Goreng. Subtotal seharusnya Rp30.000. Saat aplikasi dibuka ulang lagi, jumlah kembali nol karena pilihan hanya tersimpan di memori halaman.

  4. Bandingkan dengan kondisi tanpa cache.

    Saat server masih mati, buka URL yang sama di browser biasa, lalu di jendela Incognito baru yang belum pernah memuat demo. Terakhir, klik ganda index.html dari folder.

Cara membuka saat server matiHasilAlasan
URL HTTP · profil biasaMenu tampil.Service worker mengambil salinan dari cache yang sudah disiapkan.
URL HTTP · Incognito baruHalaman gagal dibuka.Sesi belum punya salinan dan server telah berhenti.
Klik ganda index.htmlMenu dan subtotal bisa berjalan.Browser membaca berkas langsung dari folder melalui file:///.
Hapus cache untuk mengulang uji pada profil biasa

Biarkan Live Server mati. Di tab demo beralamat HTTP, buka F12 → Application → Storage. Pilih Cache Storage dan klik Clear site data untuk alamat demo.

Di Application → Service Workers, klik Unregister jika worker masih terdaftar. Tutup semua tab dan jendela aplikasi, lalu buka URL yang sama. Halaman seharusnya gagal dibuka. Nyalakan Live Server untuk menyiapkan cache kembali.

Simulasikan offline dengan Chrome DevTools

Setelah Cache siap, pilih Network → Offline pada tab demo, lalu muat ulang biasa di tab itu. Pilih kembali No throttling setelah uji.

Percobaan akhir

Buktikan cache versi baru aktif

Mulai dari versi awal yang lulus uji offline. Simpan hasil v1 sebagai pembanding.

v1 · dua porsi Nasi GorengRp30.000
→
v2 · dua porsi Nasi GorengRp34.000

A. Ubah harga dan versi cache

Nyalakan Live Server. Di app.js, ganti baris Nasi Goreng pada daftar items dengan baris berikut.

app.js · Ganti baris harga Nasi Goreng
{ name: "Nasi Goreng", price: 17000 },

Di sw.js, ganti baris konstanta CACHE_NAME agar berakhiran v2. Simpan kedua file.

sw.js · Ganti baris CACHE_NAME
const CACHE_NAME = CACHE_PREFIX + "v2";

B. Aktifkan versi baru dan uji ulang

  1. Minta browser memeriksa pembaruan.

    Buka F12 → Application → Service Workers, klik Update bila tersedia. Worker baru dapat berstatus waiting selama versi lama masih mengontrol jendela.

  2. Tutup semua tab dan jendela Kantin Kampus.

    Buka lagi URL yang sama saat server hidup. Periksa harga Rp17.000 dan nama cache berakhiran v2.

  3. Ulangi uji offline.

    Tutup aplikasi, hentikan Live Server, lalu buka kembali. Tekan Tambah dua kali. Hasilnya seharusnya Rp34.000.

Makna hasil: worker v2 mengisi cache baru. Setelah v2 aktif, kode activate menghapus salinan v1 milik demo.

Bandingkan strategi caching
StrategiUrutan dan contoh
Cache firstGunakan salinan dahulu. Cocok untuk aset yang jarang berubah, seperti ikon dan CSS.
Network firstCoba server dahulu, lalu pakai salinan jika jaringan gagal. Cocok saat harga atau stok perlu terbaru.
Stale-while-revalidateTampilkan salinan yang tersedia sambil memperbaruinya dari server untuk permintaan berikutnya.

Demo memakai cache first. Pada sistem pesanan sungguhan, periksa harga dan stok terbaru sebelum menerima pesanan.

Checklist hasil

Jika uji offline gagal

Gunakan URL dan port yang sama dari saat Cache siap. Di Application → Service Workers, pastikan Bypass for network tidak dicentang. Jika ERR_CONNECTION_REFUSED muncul pada Incognito baru atau setelah reset, itu hasil pembanding yang diharapkan.
